Sheets, code and CAD

Everything behind the numbers on this site. The sheets are generated by the code below, so a change goes into the code, not by hand.

The Google Sheets live in the team Drive; ask a lead for access. The .xlsx copies here open in Excel, Numbers or Google Sheets.

Code

sheets/Builds every sheet with live formulas, splits it into the six files and checks every number.
analysis/Sizing sweep, spar, boom, servo, wiring, filament, duty and stability scripts.
cad/The CAD as code (build123d): every printed part, the assembly, the payload fit.
tools/This site: the parts list, the 3D model export and the page generator.

CAD files

Print pack, STL (5 MB)Every printed part in print orientation, with print settings.
STEP pack for Fusion 360 (82 MB)Every part and sub-assembly, attached to the latest release.
3D model, GLBThe model on the drone page, viewable in any glTF viewer.

Rebuild everything

python3 sheets/build_sheet.py        # all tabs with formulas
python3 sheets/calc_check.py         # recalculate, 0 errors expected
python3 sheets/split_workbooks.py    # the six files
python3 sheets/verify_split.py       # every number equals the full model
python3 tools/gen_site.py            # this site
